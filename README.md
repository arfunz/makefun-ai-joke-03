# My coding agent, the interviewer

make.fun bounty **ai-joke-03**: write the funniest one-liner about AI
coding agents.

The joke:

> My coding agent asked me one quick question before starting. That was
> 47 questions ago — I think I'm the one being interviewed now.

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt`). Deterministic: repeated runs write identical bytes.
The joke is 131 characters, within the 280-character limit.
